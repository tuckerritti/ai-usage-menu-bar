# Logo sources

These marks identify the providers whose usage is displayed. Claude and its Spark mark belong to Anthropic; ChatGPT and the OpenAI Blossom mark belong to OpenAI. This independent utility is not affiliated with or endorsed by either company.

- **ClaudeLogo**: `Claude Spark - Clay.svg`, from [Anthropic’s official press kit](https://www.anthropic.com/press-kit), [archive downloaded September 10, 2026](https://www-cdn.anthropic.com/ae59ca4ca194dac9c9dc3bc78c5829468cb0e8af.zip). The original vector path and 94 × 94 canvas are retained; the fill is black for neutral macOS template rendering.
- **ChatGPTLogo**: `OpenAI-black-monoblossom.svg`, from [OpenAI’s design guidelines](https://openai.com/brand/) and [official logo archive](https://cdn.openai.com/brand/OpenAI-Logos-2025.zip), downloaded September 10, 2026. The original black vector path and clipping paths are retained; the transparent outer canvas is reduced to the supplied inner clipping bounds, preserving the mark’s proportions. The surrounding menu label provides spacing.

The logos remain subject to their owners’ trademark and brand usage terms; they are not covered by any project code license.
